1. installera [Node.js v24](https://nodejs.org/en/download)

2. installera [Android Studio](https://developer.android.com/studio)

3. Klona repot och hoppa in i mappen
```bash
git clone https://github.com/0xNulled/webinlamning-mobil

cd webinlamning-mobil
``` 

4. Installera npm paket & dependencies
```bash
npm install
```

5. Gå igenom alla steg i [backendens README](https://github.com/0xNulled/webinlamning-ASPNET)

6. Öppna Virtual Device Manager i Android Studio 
More Actions > Virtual Device Manager > (om du inte redan har en virtual device) Add Device, följ stegen på skärmen

7. Starta en Android Virtual Device på din maskin

8. Kör Expo go
```bash
npx expo
```

9. Koppla till lokal AVD genom att trycka "a" i terminalen
