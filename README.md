1. installera [Node.js v24](https://nodejs.org/en/download)

2. Klona repot och hoppa in i mappen
```bash
git clone https://github.com/0xNulled/webinlamning-mobil

cd webinlamning-mobil
``` 

3. Installera npm paket & dependencies
```bash
npm install
```

4. Kör Expo go
```bash
npm run dev
```

5. Koppla till lokal AVD genom att trycka "a" i terminalen
